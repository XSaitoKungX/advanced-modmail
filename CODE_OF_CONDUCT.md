# Code of Conduct

## Our standards

Advanced Modmail is intended to be a professional and welcoming open-source project.

Participants are expected to:

- communicate respectfully and constructively,
- critique ideas and code rather than people,
- respect privacy and confidential security information,
- avoid harassment, discrimination, threats, personal attacks, and deliberate disruption,
- assume good faith while remaining clear about technical and security requirements.

Unacceptable behavior includes harassment, discriminatory language, sexualized attention, doxxing, threats, sustained trolling, or publishing another person's private information without permission.

## Scope

These expectations apply in project spaces including issues, pull requests, discussions, reviews, and other official project communication channels.

## Enforcement

Reports should be sent privately to the project maintainer. Reports are reviewed in context and may result in warnings, content removal, temporary participation restrictions, or permanent exclusion from project spaces depending on severity and pattern.

Security vulnerabilities should follow `SECURITY.md` rather than this process.

## Attribution

This project-specific code of conduct is inspired by common open-source community standards, including the Contributor Covenant, but is intentionally maintained in a concise project-specific form.
