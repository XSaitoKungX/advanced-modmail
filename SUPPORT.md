# Support

## Project questions

Use GitHub Discussions for general questions, architecture discussions, usage questions, and ideas that are not yet actionable bug reports or feature requests.

## Bugs

Use the Bug Report issue form and include reproducible steps, expected behavior, actual behavior, and relevant environment details.

## Feature requests

Use the Feature Request issue form. Explain the problem first, then the proposed solution.

## Security

Do not use public issues for vulnerabilities. Follow `SECURITY.md`.

## Current availability

Advanced Modmail is in pre-alpha development. There is currently no stable release and no guaranteed support SLA.
